# 星芽英语完整课程升级实施计划

> 当前计划在既有静态 PWA 上实施，保持 GitHub Pages 和 Sites 双发布。

**目标：** 将 5 题体验版升级为具有 6 单元、24 课、错题复习、课程进度、家长报告和真实风格订阅结算界面的完整幼小衔接英语软件。

**架构：** 以课程数据、课程状态、学习计分、订阅结算和 UI 编排五个模块分离实现。所有学习状态只保存在本机；课程与页面均为静态资源，可离线运行。

**技术栈：** 原生 HTML、CSS、ES Modules、Web Speech API、LocalStorage、Service Worker、Node 内置测试运行器、GitHub Actions Pages。

---

## 任务一：锁定课程和订阅行为

**文件：** 新建 `tests/course-engine.test.js`；修改 `tests/learning-engine.test.js`、`tests/subscription.test.js`。

先编写会失败的行为测试，覆盖 6 单元、24 课、每课 7 个活动、A～Z 覆盖、唯一答案、顺序解锁、错题优先复习、完成课程记录，以及 19.9 元/月套餐在最终支付时返回“开发中”且不产生订单和激活状态。运行 `npm test`，确认新测试因缺少模块和旧订阅实现而失败。

## 任务二：建立完整课程目录与学习引擎

**文件：** 新建 `dist/js/course-data.js`、`dist/js/course-engine.js`；修改 `dist/js/learning-engine.js`。

使用稳定的课程模板生成 24 节课和 168 个活动，确保每课内容围绕一个明确主题、4～5 个字母目标、5 个核心词汇和 1 个高频句型。实现课程扁平化、校验、解锁、下一课、错题复习与完成记录；扩展学习进度以保存课程和错题状态。运行 `npm test`，直到课程和学习引擎测试全部通过。

## 任务三：替换订阅状态机

**文件：** 修改 `dist/js/subscription.js`。

删除模拟激活逻辑，提供固定套餐描述和不可用结算结果。结算结果只包含 `status: unavailable` 和开发中提示，不包含订单、付款人、支付 ID、激活时间或本地订阅状态。运行订阅测试，确认通过。

## 任务四：构建五个完整产品界面

**文件：** 修改 `dist/index.html`、`dist/css/styles.css`、`dist/js/app.js`。

重做首页当前课程卡和成长概览，新增课程地图、复习中心和主题贴纸；升级单课流程为 7 题并支持从课程或复习入口启动；扩展家长中心为五项能力、课程要求和课程总览。重做 19.9 元/月微信支付结算对话框，最终动作展示开发中状态，不显示模拟文案或成功状态。保持长按进入家长中心、语音朗读、无障碍标签和响应式布局。

## 任务五：离线资源与静态校验

**文件：** 新建 `scripts/generate-audio.mjs` 和 `dist/assets/audio/*.wav`；修改 `dist/sw.js`、`scripts/static-check.mjs`。

为 168 个活动生成随站发布的英语发音文件，移动端优先使用站内音频并以系统英文朗读作为兜底。升级缓存版本，加入新课程模块，扩展必需文件、音频数量和语法校验。运行 `npm test`、`npm run check` 和 `git diff --check`，修复所有失败。

## 任务六：真实浏览器验收

启动本地静态服务器，在桌面和 390×844 手机视口验证：首页显示当前课，课程页包含 6 单元和 24 课，第一课可进入并完成 7 题，下一课解锁，复习入口可用，家长中心订阅按钮进入结算，最终点击只出现开发中提示，且页面没有“模拟订阅”字样或横向溢出。
