# 幼小衔接英语 PWA 设计说明

## 一、产品目标

产品暂定名为“星芽英语”，面向幼儿园大班儿童。孩子打开软件后，无需识字或登录，就能在语音引导下独立完成约 8—10 分钟的英语练习。首版的目标不是覆盖小学英语全部知识，而是建立英语声音、图片、字母和简单表达之间的联系，并形成稳定、轻松的每日学习习惯。

家长不参与日常答题，但可以通过长按进入家长页，查看累计学习天数、正确率、星星数和近期薄弱类型。学习记录只保存在当前设备，不上传儿童姓名、声音或其他个人信息。

## 二、方案比较与选择

方案一是无后端的单页 PWA，使用浏览器语音合成播放英语，使用本机存储保存进度。它的优点是打开快、安装简单、离线可用、没有儿童隐私上传风险，缺点是不同设备的英语发音音色会略有差异。首版选择此方案。

方案二是带账号和云同步的 Web 应用，可以跨设备保存记录并由家长远程查看，但需要服务器、账户系统和更严格的儿童隐私设计，不适合首版验证。方案三是原生安卓应用，语音和通知能力更强，但开发、安装和后续兼容成本更高，待 PWA 验证学习流程后再考虑。

## 三、核心学习体验

首页直接呈现今日旅程，不设置营销页。孩子点击“开始今天的冒险”后进入五题学习流程，每次只显示一个任务，包含字母认知、听音选图、词义匹配和简单句型四类活动。按钮尺寸适合触摸，界面尽量少字，所有关键英文均可点击扬声器重复播放。

每次作答都会立即反馈。正确时播放鼓励语、获得星星并自动进入下一题；答错时不扣星，突出正确答案并允许孩子再听一次。完成五题后显示本次正确数、获得星星和一句积极反馈，孩子可以回到首页或再练一次。

首版课程使用幼小衔接高频主题“彩虹野餐”，涵盖 A、B、C 三个字母及 apple、ball、cat、red、blue、hello 等词语。内容数据与练习引擎分离，后续可以增加数字、家庭、动物、学校等主题，而无需重写界面逻辑。

## 四、界面与视觉

视觉主题为“明亮的星光森林探险”。主色使用深蓝与明亮黄色，辅助色使用草绿和天空蓝，确保白底上的文字对比清楚。首页用一张原创猫头鹰向导插画建立陪伴感；活动卡片采用清晰的色块、柔和圆角和轻量动效，但不让动画遮挡题目或拖慢操作。

移动端以单列为主，主要操作位于拇指容易触达的下半屏；桌面端将今日任务和成长信息并排展示。所有常用文字不小于 16 像素，主要按钮高度不小于 56 像素，并支持键盘焦点、减少动态效果和系统字体放大。

## 五、数据、隐私与异常处理

学习记录包含完成日期、答题数量、正确数量、获得星星和各活动类型结果，保存于浏览器 localStorage。应用不采集真实姓名、不录音、不请求麦克风、不连接第三方分析服务。清除记录需要在家长页二次确认，避免孩子误触。

若浏览器不支持语音合成，应用仍显示英文单词，并提示家长当前设备暂不支持朗读；若本机存储不可用，本次课程仍可继续，但会提示记录无法保存。断网时，Service Worker 缓存应用壳和插画，已打开过的软件仍可启动。

## 六、验收标准

软件必须可以从首页开始并完成一轮五题练习，正确与错误答案均有明确反馈，完成后能保存并更新累计数据。刷新页面后学习记录仍存在，家长入口需要持续长按才能打开，重置记录必须经过确认。PWA 必须包含有效的清单文件和离线缓存脚本，并能在手机与桌面宽度下无横向溢出。

核心学习逻辑需要通过自动化测试覆盖题目生成、答案判断、星星计算和学习记录汇总。HTML、JavaScript、PWA 资源引用和页面入口需要通过静态检查，最终页面由本地 HTTP 服务成功返回。
